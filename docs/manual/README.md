# Trag user manual

This manual explains how to work with Trag, from adding your first repository to merging, rebasing and syncing with
GitHub and GitLab. Every chapter has screenshots of the real application.

## Chapters

1. [Repositories](01-repositories.md) - the repository list, adding, cloning, removing and opening repositories
2. [The main window](02-main-window.md) - the toolbar, the sections, branches, stashes, tags and keyboard shortcuts
3. [Committing changes](03-committing.md) - reviewing diffs, staging files, hunks and lines, discarding, committing and amending
4. [History](04-history.md) - the commit graph, commit details, going to a commit, search, file history and blame
5. [Branches and tags](05-branches-and-tags.md) - switching, creating, renaming and deleting branches, and working with tags
6. [Merging and rebasing](06-merging-and-rebasing.md) - merge, rebase, cherry-pick, revert, reset and editing commits
7. [Resolving conflicts](07-resolving-conflicts.md) - choosing sides block by block, marking files resolved, finishing or aborting
8. [Stashes](08-stashes.md) - setting work aside, previewing, applying and dropping stashes
9. [Syncing with remotes](09-syncing.md) - fetch, pull, push, force push, publishing branches and repositories, and remotes
10. [Accounts and settings](10-accounts-and-settings.md) - GitHub and GitLab accounts, automatic fetch, Git, themes and About

## About the screenshots

The screenshots show Trag with the light theme and a set of example repositories. All names, people and addresses in
them are made up.
